# Soul Society

Repository ini berisi implementasi deployment Kubernetes untuk proyek **Soul Society**.

Seluruh manifest Kubernetes dapat ditemukan pada direktori:

```text
k8s/
```

Direktori tersebut mencakup seluruh resource yang diperlukan untuk melakukan deployment aplikasi ke Kubernetes, seperti namespace, services, deployments, statefulsets, configmaps, RBAC, dan komponen pendukung lainnya.
